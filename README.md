# Portfolio Radar

Tägliches Aktien-Dashboard mit Elliott-Wellen-Analyse und News. Wird werktags automatisch aktualisiert (ca. 14:15, 17:45, 22:15 Uhr).

- `index.html`, `app.js`, `app.css`, `logo.svg` – die Seite (Dark Mode, Seiten Aktien / News / Ausblick)
- `data/*.json` – Daten des letzten Updates
- `scripts/export_public.py` – kopiert Dashboard-Daten ohne private Beträge hierher

Keine Anlageberatung.
